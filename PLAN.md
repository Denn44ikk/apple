Дополнение: опубликовать отдельную ссылку для тестирования версии 2 на iPhone с нейтральным названием, не меняя ссылку версии 1.

Дополнение: подготовить отдельный нативный iOS-проект для подписи в аккаунте Apple Developer заказчика и выпуска `.ipa`/TestFlight-сборки.

## Решения

- Фото трактуется как пример недельной сводки: семь дней, у каждого видны задачи и процент выполненных. Для читаемости iPhone дни будут располагаться вертикально.
- Существующая публичная версия и ветка `main` не меняются.
- Название для заказчика: «Мой план — версия 2»; короткий нейтральный адрес без имени платформы в слаге, насколько позволяет хостинг.
- `.ipa` должна быть подписана сертификатом и профилем владельца Apple Developer; финальная подпись и экспорт выполняются в Xcode на macOS.
- Выделена ветка `ios-v2` и worktree `planner-prototype-ios`; она не меняет `main`, `version-2` или опубликованный веб-прототип.
- Подписывание в GitHub Actions будет выполняться только из encrypted repository secrets; сертификаты, пароли и Apple Account не добавляются в исходный код.

## Проверка и риски

`check:runtime` и сборка TypeScript/Vite прошли. Прошли 4 теста Sites, 8 тестов мобильного рантайма и 4 теста поведения версии 2. В iPhone превью вручную проверены группировка, неделя, пересчёт процента и закреплённая навигация. Скриншоты и сравнение с рисунком сохранены в `qa/`; отчёт `design-qa.md` имеет статус `passed`.

Публичная версия 1 не обновлялась. Версия 2 опубликована отдельно: `https://moy-plan-v2-test.turaldeod.chatgpt.site`. Статус публикации — `succeeded`, доступ — `public`, название — «Мой план — версия 2». Локальная ветка — `version-2`.

Проверка на iPhone: открыть ссылку в Safari, в «Списке» проверить группы категорий, в «Неделе» — карточки дней, задачи и проценты; изменить выполнение задачи и убедиться, что процент пересчитался; добавить задачу с категорией и проверить её появление. Это браузерный прототип, не сборка App Store/TestFlight; данные демонстрационные и могут сбрасываться после перезагрузки страницы. Домен хостинга содержит `chatgpt.site`; для полностью нейтрального адреса потребуется собственный домен.

Нативная сборка подготовлена в ветке `ios-v2`: Capacitor 8.5.2, iOS 15+, Bundle ID `ru.moyplan.planner`, локальный пакет `dist/client`. `npm run ios:sync`, 12 Playwright-тестов и 4 Sites-теста прошли. Подписанный `.ipa` невозможно корректно создать без сертификатов и provisioning profile аккаунта заказчика на macOS; подробный процесс описан в `IOS_BUILD.md`.

Инструкция `ИНСТРУКЦИЯ_ДЛЯ_АЙФОНА.txt` приведена к формату нумерованных действий без вводных разделов.

В ветке `ios-v2` добавлен `iOS signed build` для GitHub Actions и инструкция `GITHUB_ACTIONS_ПОДПИСЬ.txt`. Реальный запуск потребует приватный GitHub-репозиторий и секреты подписи; они намеренно не хранятся локально и не добавляются в код.

Добавлен самостоятельный список действий `ДЕЙСТВИЯ_ДЛЯ_ПОДПИСИ_И_TESTFLIGHT.txt` без вводных разделов.
