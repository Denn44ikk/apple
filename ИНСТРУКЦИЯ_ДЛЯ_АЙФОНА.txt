1. Подготовь iPhone, Apple Account, Mac или MacBook, доступ в интернет и банковскую карту.

2. На iPhone открой «Настройки» → своё имя → «Пароль и безопасность».

3. Включи двухфакторную аутентификацию.

4. Открой App Store.

5. Найди приложение Apple Developer.

6. Установи и открой Apple Developer.

7. Нажми Account.

8. Войди под Apple Account.

9. Нажми Enroll или Enroll Now.

10. Выбери Individual, если приложение будет опубликовано от имени человека.

11. Выбери Organization, если приложение будет опубликовано от имени компании.

12. При выборе Individual укажи настоящее имя, фамилию, телефон и адрес.

13. При выборе Organization укажи официальное название компании, рабочую почту, телефон, адрес, сайт и номер D-U-N-S.

14. Если номера D-U-N-S нет, нажми ссылку Apple для его запроса и заполни форму.

15. Проверь имя человека или название компании. Оно будет показано в App Store рядом с приложением.

16. Прими условия Apple Developer Program License Agreement.

17. Оплати Apple Developer Program.

18. Проверь сумму перед оплатой. Обычно это 99 USD в год или сумма в местной валюте, если Apple её предлагает.

19. Дождись письма Apple о подтверждении членства.

20. Открой на Mac сайт https://appstoreconnect.apple.com/.

21. Войди под тем же Apple Account.

22. Проверь, что открывается раздел Apps.

23. Установи Xcode из Mac App Store.

24. Скопируй папку planner-prototype-ios на Mac.

25. Открой Terminal на Mac.

26. Введи команду cd, поставь пробел, перетащи папку planner-prototype-ios в окно Terminal и нажми Enter.

27. Выполни команду:

   npm ci

28. Дождись окончания установки.

29. Выполни команду:

   npm run ios:sync

30. Дождись сообщения Sync finished.

31. Открой Finder.

32. Открой папку planner-prototype-ios → ios → App.

33. Дважды нажми App.xcodeproj.

34. В Xcode в левой колонке нажми App с синим значком проекта.

35. В центральной части выбери TARGETS → App.

36. Открой вкладку Signing & Capabilities.

37. Поставь галочку Automatically manage signing.

38. В поле Team выбери свою команду Apple Developer.

39. Проверь поле Bundle Identifier.

40. Если Xcode не показывает ошибку, оставь значение ru.moyplan.planner.

41. Если Xcode сообщает, что Bundle Identifier занят, укажи другой уникальный вариант, например ru.название-компании.moyplan.

42. Если Bundle Identifier был изменён, открой файл capacitor.config.ts в папке planner-prototype-ios.

43. Найди строку appId.

44. Укажи в appId то же значение, что в Bundle Identifier в Xcode.

45. Сохрани файл.

46. Вернись в Terminal.

47. Выполни команду:

   npm run ios:sync

48. Вернись в Xcode.

49. Проверь, что в Signing & Capabilities нет красных ошибок.

50. В Xcode открой App → App → Assets.xcassets → AppIcon.

51. Подготовь квадратную иконку PNG 1024 x 1024 пикселя без прозрачного фона.

52. Перетащи иконку в поле App Store iOS 1024pt.

53. Открой https://appstoreconnect.apple.com/.

54. Нажми Apps.

55. Нажми знак +.

56. Нажми New App.

57. Выбери iOS.

58. В поле Name введи Мой план.

59. Выбери основной язык.

60. В поле Bundle ID выбери тот же идентификатор, который указан в Xcode.

61. В поле SKU введи MOYPLAN-001.

62. Нажми Create.

63. Вернись в Xcode.

64. В верхней части окна нажми на выбранное устройство.

65. Выбери Any iOS Device (arm64).

66. В верхнем меню нажми Product → Archive.

67. Дождись окончания сборки и открытия окна Organizer.

68. Выбери созданный архив.

69. Нажми Distribute App.

70. Выбери App Store Connect.

71. Выбери Upload.

72. Нажимай Next, оставляя рекомендуемые настройки Xcode.

73. Нажми Upload.

74. Дождись сообщения Upload Successful.

75. Открой https://appstoreconnect.apple.com/.

76. Открой приложение Мой план.

77. Открой вкладку TestFlight.

78. Дождись обработки сборки. Рядом со сборкой не должно быть статуса Processing.

79. Если Apple спросит о шифровании, выбери ответ в соответствии с возможностями приложения.

80. Нажми кнопку добавления тестировщика.

81. Введи Apple Account, который используется на iPhone.

82. Выбери загруженную сборку.

83. Отправь приглашение.

84. На iPhone открой App Store.

85. Найди TestFlight.

86. Установи TestFlight.

87. Открой на iPhone письмо с приглашением в TestFlight.

88. Нажми View in TestFlight или Start Testing.

89. В TestFlight нажми Install рядом с приложением Мой план.

90. Дождись установки.

91. Открой приложение с иконки на экране iPhone.

92. Открой https://appstoreconnect.apple.com/ на Mac.

93. Открой приложение Мой план.

94. Открой раздел App Store.

95. Создай новую версию iOS.

96. Заполни описание приложения.

97. Укажи категорию приложения.

98. Заполни возрастной рейтинг.

99. Добавь иконку приложения.

100. Добавь скриншоты iPhone.

101. Укажи ссылку на политику конфиденциальности.

102. Укажи контактные данные.

103. Выбери загруженную сборку.

104. Нажми Add for Review или Submit for Review.

105. Ответь на вопросы Apple.

106. Дождись решения Apple.

107. После одобрения открой App Store на iPhone.

108. Найди приложение Мой план.

109. Нажми Получить.

110. Открывай приложение с иконки на экране iPhone.

111. После изменений открой Terminal на Mac.

112. Перейди в папку planner-prototype-ios.

113. Выполни команду:

   npm run ios:sync

114. Открой App.xcodeproj в Xcode.

115. Увеличь значение Build на 1.

116. Повтори пункты 64–74 для загрузки новой сборки.

117. Повтори пункты 75–83 для TestFlight.

118. Повтори пункты 92–106 для обновления через App Store.
